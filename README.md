# Эффективность пяти ИТ-команд

Автор Екатерина Дружинская.

Сайт: https://druzhinskaia.github.io/team-performance-analysis/

интерактивный отчёт с просмотром Excel, презентации и инструкции. В `files/final_package.zip` — три итоговых файла: Excel, PowerPoint и Word.

Исходный код находится в `source/`. Сборка: `python3 source/build.py`. Файлы для просмотра находятся в `views/slides/`, документы — в `files/`. Все ссылки относительные и работают в каталоге GitHub Pages.
