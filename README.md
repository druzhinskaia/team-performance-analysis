# Эффективность пяти ИТ-команд

Автор: Екатерина Дружинская.

Сайт: https://druzhinskaia.github.io/team-performance-analysis/

Интерактивный отчёт с просмотром Excel, презентации и инструкции. Итоговый ZIP содержит четыре документа: Excel с исходным ТЗ и расчётами, презентацию PowerPoint, презентацию PDF и инструкцию Word.

Исходники сайта находятся в source/. Сборка: python3 source/build.py. Документы находятся в files/, изображения слайдов — в views/slides/.

В Excel добавлены проверки исходных данных, точное отображение процентов и динамические числовые пояснения. Сайт и презентация показывают текущий проверенный срез; после замены исходных значений в Excel их нужно обновлять отдельно.
